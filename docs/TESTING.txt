SNAKE MAX — проверка перед сдачей

Автоматические тесты:
python -m unittest discover -s tests -v

Ручные проверки:
1. Запустить python main.py.
2. Проверить три режима и три сложности.
3. Проверить стрелки, WASD, паузу и новую игру.
4. Завершить партию и проверить сохранение рекорда.
5. Перезапустить приложение и проверить рекорды.
