# SNAKE MAX — «Змейка на максималках»

Учебный курсовой проект по объектно-ориентированному программированию.

## Запуск (Windows / Linux / macOS)

1. Установить Python **3.10 или новее** с поддержкой Tkinter. Для Windows Tkinter обычно входит в стандартную установку Python; Linux может потребовать `python3-tk`.
2. Распаковать проект и открыть командную строку в папке `snake_max_project`.
3. Запустить:

```bash
python main.py
```

Внешних Python-пакетов игра не требует.

## Управление

| Кнопки | Действие |
|---|---|
| Стрелки / WASD | Перемещение змейки |
| Space | Пауза / продолжение |
| Enter | Запуск (из меню), повторный запуск после проигрыша |
| R | Новая игра |
| G | Показать / скрыть сетку |
| Кнопка «?» | Правила игры и список бонусов |

## Механика

- **Аркада**: обычные стены и препятствия, два портала.
- **Выживание**: больше препятствий, по два новых после каждых 6 обычных съеденных яблок.
- **Дзен**: нет препятствий и порталов, при выходе за границу происходит перенос на противоположную сторону.
- **Сложность**: лёгкая (180 мс/ход), нормальная (135 мс/ход), сложная (100 мс/ход). Темп повышается по мере сбора еды.
- **Обычная еда**: +10 очков, рост змейки на 1 клетку.
- **Золотая еда**: +50 очков, появляется после каждых 5 обычных яблок, исчезает через 36 ходов.
- **Усиления** появляются случайно каждые 28 ходов, существуют до 50 ходов: `2×` удваивает очки, `◇` разрешает проход через препятствия и тело, `◷` снижает скорость. Выход за границу в аркаде/выживании остаётся смертельным даже с бонусом «Призрак».
- **Рекорды**: автоматически сохраняются при завершении партии в `~/.snake_max/records.json` (отображается топ-5, хранится топ-20).

## Связь с требованиями ООП

В проекте **18 предметных классов** (не учитывая Enum):

1. `Position` — координаты игрового поля;
2. `GameSettings` — настройки;
3. `Snake` — змейка;
4. `Entity` — абстрактный родитель всех объектов;
5. `Food` — обычная еда;
6. `GoldenFood` — золотая еда;
7. `PowerUp` — абстрактный родитель усилений;
8. `DoublePoints` — удвоение очков;
9. `GhostMode` — проход сквозь препятствия;
10. `SlowMotion` — замедление;
11. `Obstacle` — препятствие;
12. `Portal` — портал;
13. `LevelGenerator` — генератор карты;
14. `CollisionSystem` — проверка столкновений;
15. `ScoreManager` — хранение рекордов;
16. `GameEngine` — игровая модель;
17. `GameRenderer` — представление;
18. `SnakeGameApp` — контроллер и окно.

Всего **18 классов**, если считать `Position` и `GameSettings`; из них `Entity` и `PowerUp` абстрактные.

- **Инкапсуляция:** `Snake` хранит `_segments`, `_direction`, `_queued_direction` приватизированными по соглашению Python, а наружу предоставляет `head`, `segments`, `turn()`, `move()`. Свойство `segments` возвращает неизменяемый кортеж. `ScoreManager` закрывает путь файла `_path`.
- **Наследование:** `Food(Entity)`, `GoldenFood(Food)`, `PowerUp(Entity)`, `GhostMode(PowerUp)`, `SlowMotion(PowerUp)`, `DoublePoints(PowerUp)`, `Obstacle(Entity)`, `Portal(Entity)`.
- **Полиморфизм:** общий метод `on_collect(engine)` вызывается для `Food`, `GoldenFood` и бонусов, но выполняет разные действия. `PowerUp.activate(engine)` реализуется по-разному в дочерних классах; отрисовка разных объектов выполняется с помощью общего интерфейса `color` / `glyph`.
- **Абстракция:** интерфейс `Entity`, `PowerUp` через `ABC` и `@abstractmethod`, отдельные подсистемы генерации, столкновений, отображения и сохранения.

## Тестирование

```bash
python -m unittest discover -s tests -v
```

Проверяются повороты и рост змейки, наследование/полиморфизм еды и бонусов, столкновения, перенос через границу, пауза, конфигурация и сохранение рекордов.

## UML

Файлы `.puml` можно открыть в расширении **PlantUML** для VS Code или на локальном PlantUML-рендерере. Также доступны исходники `.mmd` для Mermaid. Диаграммы отображают наследование, агрегацию/композицию и последовательность действий во время одного игрового хода.
